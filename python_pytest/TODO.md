# 整数の閉区間

## 仕様

整数閉区間を示すクラス（あるいは構造体）をつくりたい。整数閉区間オブジェクトは下端点と上端点を持つ。ただし、上端点より下端点が大きい閉区間を作ることはできない。整数の閉区間は文字列表記を返せる（例: 下端点 3, 上端点 8 の整数閉区間の文字列表記は "[3,8]"）。また、整数の閉区間は指定した整数を含むかどうか、別の閉区間と等価かどうか、完全に含むかどうかを判定できる。
